# Top Countries Email Marketing Metrics

## Project Overview
This project analyzes email marketing performance across different countries using SQL and Google BigQuery.

## Objectives
- Calculate the number of unique accounts by country.
- Analyze email campaign metrics:
  - Sent emails
  - Opened emails
  - Email visits
- Rank countries by account activity and email volume.
- Identify the Top 10 countries based on key metrics.

## Technologies
- SQL
- Google BigQuery
- CTEs (Common Table Expressions)
- Window Functions
- DENSE_RANK()

## Output
The project creates a view called `top_countries_email_metrics` that combines account and email engagement metrics and provides rankings for top-performing countries.
